# security

The configuration behind the four security moments.

OneLake roles, the Sentinel analytics rules and the custom table they query, the
Foundry guardrail, and the AI gateway limits.

Keep each one next to a note of what it is supposed to stop, so the demo can show
the defence and the effect rather than a settings page.

The security tests that exercise these live in `tests/` and are marked
`@pytest.mark.security`.
