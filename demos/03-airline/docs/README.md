# docs

What the demo is, how it is built, and where it stands.

- `demo-spec.md` — the contract: storyline, data contract, rules, approval policy,
  expected results, what is out of scope.
- `BUILD_SCRIPT.md` — the full build script, phase by phase.
- `status.md` — one row per phase: state, how it was verified, what is open.
- `manual-steps.md` — everything a person has to do by hand, and why.
- `verify-list.md` — the points where the documentation is in preview, silent or
  contradictory, and the limits of this design. Each phase closes the ones it
  touches.

Runbooks and demo-day notes belong here too.
